# AI ATS Resume Screener

## Features

- Upload Multiple Resume PDFs
- Extract Resume Text
- Compare with Job Description
- ATS Match Percentage
- Matching Skills
- Missing Skills
- Recommendation
- Matched Candidates
- Unmatched Candidates
- CSV Download

## Installation

```bash
pip install -r requirements.txt
```

## Add API Key

Create .env file

```env
HF_API_KEY=your_token_here
```

## Run

```bash
streamlit run app.py
```
